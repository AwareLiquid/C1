# E5 — 多视野统一输出：一个模型同时管短视野与长视野

> 状态：🟡 设计完成（代码就绪，待 GPU 全量；合成冒烟已过）
> 对标：**EnergyTS「长短时路径统一架构」**（蚂蚁数科新能源时序大模型一体机，2026-09 行业观察）——
> 一个模型同时服务 15min 级短时预测与日前/多日长时预测，是其四大 SOTA 场景的统一底座。
> 核心问题：**同一套液态多尺度栈，能否在统一架构下同时达到短视野（分钟级）与长视野（日级）的预测质量？**

---

## 1. 动机

EnergyTS 的公开材料把「长短时路径统一架构 + 多尺度预训练」列为核心卖点：单一模型覆盖
光伏/风电/负荷/电价四场景，且 96 点（15min 粒度）日前精度与实时预测用同一架构。这验证了
我们在 MT-LNN 里已经押注的方向——**多尺度 τ 阶梯本来就是"快 τ 管近未来、慢 τ 管远未来"
的连续时间实现**。但我们从未验证过：τ 阶梯能否支撑**跨数量级的视野跨度**。

E2 已经实现了 k 步前瞻头（token MTP + 状态前瞻），E3 已经实现了时间尺度数扫描
（n_scales 5/8/16 × top-k）。E5 = **E2 的视野维度 × E3 的尺度维度**：同一实验矩阵的新单元格。

## 2. 假设

**H-E5**：在统一架构（同一主干 + 多视野头）下，液态模型的短视野（h=8）与长视野（h=128）
误差同时达到各自单视野专用模型的水平；且长视野对**时间尺度数**的敏感度显著高于短视野
（慢 τ 是长视野的载体）。

## 3. 实验设计

### 配置矩阵

| 维度 | 取值 | 说明 |
|---|---|---|
| 视野集合 h | {8, 32, 128}（seq_len=512）| 短/中/长，对应分钟级→日级跨度 |
| 时间尺度数 n_scales | {5, 8, 16} | E3 的旋钮 |
| 损失权重 | w_h = 1/√h（默认 `inv_sqrt`，均值归一为 1；可选 `inv`/`equal`）| 衰减加权，长视野保留足够信号 |
| 对照 | 单视野专用模型（同预算只训 h=8 或只训 h=128）| "统一 vs 专用"的差距 |

### 指标

1. **逐视野 PPL**（每 h 独立评估）——统一模型 vs 专用模型
2. **视野跨度增益**：长视野（h=128）在 n_scales=16 vs 5 下的改善幅度（验证慢 τ 假设）
3. **跨视野一致性**：三个视野的最差视野相对最优视野的差距（统一架构的"木桶"）

## 4. 预注册判据（跑之前写死）

- **统一架构成立** ⇔ 统一模型在全部 3 个视野上的 PPL 均 ≤ 对应单视野专用模型的 1.10×（10% 容忍带）；
- **慢 τ 假设成立** ⇔ h=128 在 n_scales=16 相比 n_scales=5 的相对改善 ≥ 短视野（h=8）改善的 2×；
- 任一不成立 → 如实记负结果（"统一架构无优势"或"尺度数与视野无关"），不事后移动判据。

## 5. 产出

- `experiments/e5_multi_horizon.py`：可跑脚本（`--horizons`/`--n_scales`/`--smoke`）
- 结果 JSON：逐视野 PPL 矩阵（3 视野 × 3 尺度 × 3 seeds）
- 判定：统一多视野架构是否成立；n_scales 对长视野的边际收益

## 6. 依赖与边界

```bash
# 合成冒烟（CPU，零数据文件）
python experiments/e5_multi_horizon.py --smoke --horizons 8 32 --n_scales 5 --steps 3 --seeds 0
# GPU 全量（WikiText 或合成长序列，待租卡）
python experiments/e5_multi_horizon.py --d_model 832 --n_layers 12 --steps 4000 --seeds 0 1 2
```

- **诚实边界**：本实验在语言建模/合成序列口径验证"多视野统一"的架构性质，
  **不等于** EnergyTS 那种真实电力场景 SOTA——真实域结论需要能源数据管线（另行任务）。
- 与 E2 的区别：E2 问"多步前瞻是否加速收敛"，E5 问"视野跨度是否需要不同尺度容量"——
  同一头机制，不同科学问题。
