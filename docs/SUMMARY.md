> 本文件汇总 2026-09-12 起在单卡 A100-PCIE-40GB 上连续推进的 C1(Cortex)实验队列。
> 每批结果详见 `S{n}_RESULTS.md`;原始 JSONL 在各批 `results_s{n}/`(服务器,未入库)。
> 纪律:每批结论独立入库并 push;发现实现 bug 先修复再重跑。

## 1. 实验队列与结论

| 批次 | 内容 | 结论 |
|---|---|---|
| **S1** | E1 液态 GRPO / E2 MTP / E3 时间尺度 | 三者全负(E1 GRPO ≈ 随机;E2 MTP 无增益;E3 地板效应) |
| **S2** | E3 已验证协议 / E2 长预算 / E1 热启 GRPO | E3 可学但无外推;E2 中性;**E1 热启 GRPO 破坏性**(把已收敛模型打崩) |
| **S3** | E1 GRPO 稳定化 / E3 尺度确认 | GRPO 稳定化**修复成功**(模型不再崩);E3 尺度信号仍弱 |
| **S4** | E5 多视野统一 / E6 跨域零样本 | **E5 首个正信号**(统一主干利于长视野);E6 域依赖 |
| **S5** | E5 6-seed / E6 5-seed 确认 | E5 长视野优势确证;E6 域依赖确证(events 可迁移,ar 不可) |

| **S10** | E5 @1040/16L 长预算 8000 步 | 进行中(S8 是否只是欠训练) |

## 2. 核心正面结论(E5)

*共享主干 + 每视野一个头* 的统一架构,相对"每视野单独一个模型":
- **长视野(≥16,到 512)稳定更优(6%~15%)**,且方差更小 —— 在 125M(832/12L)上跨 2000/4000/8000 步稳健。
- 短视野(≤8)两者在噪声内互有胜负。
- **规模边界**:该优势在 1040/16L @4000 步未保持(S8);S10 检验是否是欠训练。
- 默认头权重 `inv_sqrt` 最优。

## 3. 明确负结果

- **E1 液态 GRPO**:从零/热启都未涌现长度外推;且原实现有优势爆炸 bug(已修)。
- **E2 MTP**:token/状态前瞻在 2000/6000 步均无 PPL 增益,state-mtp 略差。
- **E3 时间尺度扩容**:改为 M1 已验证 parity 协议后可学,但无长度外推;尺度信号弱。
- **E6 跨域零样本**:域依赖 —— 稀疏事件流可迁移,强自回归域不可。

## 4. 过程中发现并修复的实现 bug（均已推送）

| 位置 | bug | 影响 |
|---|---|---|
| `fix(e3)` | `--topk` 未接线(应写 `sparse_resonance_kernel`/`topk`) | 所有 top-k 配置实为 dense,实验无效 |
| `fix(e3)` | 手写 parity 非 M1 协议 | 任务学不会(地板效应) |
| `fix(e1)` | GRPO 优势 `/(std+1e-4)` 在近完美策略下爆炸 | 热启 GRPO 把已收敛模型打崩 |
| `fix(e2)` | MTP 头预测同位置 token(信息泄漏)+ 评估用未训练 lm_head | baseline loss 坍缩、val PPL ~6e4 无意义 |
| `fix(e5)` | 视野 ≥ seq_len 时 loss 变 float / dedicated 崩溃 | E5 在 h=512 崩/退化 |

## 5. 方法学备注

- 序列任务(E1/E3)存在 **grokking 双峰**:同配置不同 seed 可能"学会"或"随机",需多 seed 才稳。
- 该随机性使 n=2 的结论不可靠;E5(S5/S9)用 6 seeds 才确证长视野优势。
- 所有实验脚本在 A100 上经 tmux 常驻运行,`results_s*/` 落盘,`S*_DONE` 标记完成。
