# E7 — 数据形态探针：类脑机制是否有"受力面"

> 状态：🟢 探针 A 已结案 DEAD（2026-09-16，A100 全量 3-seed）——见 [E7_RESULTS.md](E7_RESULTS.md)；
> 探针 B（输入依赖 dt）按预注册分支启动
> 对标：**"数据源 = L1"定性**（ARCHITECTURE_C1 §1，2026-09-12）——类脑机制在标准 LLM
> 静态语料（固定块 + 均匀 dt）上没有受力面，需验证流式形态是否真的不同。
> 核心问题：**同样模型、同样预算、同样 token，换一种"切块与时间形态"，液态栈的表现是否显著改变？**

---

## 1. 动机

三条实证线索指向同一个假设：**我们的机制被数据形态压制了**——
① PPL 与同参数 transformer 打平；② B-1 selective_decay 在 WikiText 固定块上 DEAD；
③ 唯一真差异化（不规则采样 +7.7% vs LSTM/GRU +31~33%）出现在带真实 Δt 的电池流上。

E7 用**最便宜的两个探针**验证"形态有没有受力面"：

| 探针 | 改动 | 成本 |
|---|---|---|
| **A. 事件边界切片**（本脚本，零模型改动） | 数据侧：按句/段边界切块 + 边界处标签忽略，vs 固定任意切块 | 纯管线，CPU 可全量 |
| **B. 输入依赖 dt**（需 patch，A 结案后写） | 模型侧小改：`decay = exp(−dt_t/τ)`，dt_t 由输入驱动（电池边侧 gamma(dt) 模式的文本线移植） | ~10 行层内 patch + 管线 |

## 2. 假设

- **H-E7A**：事件边界切块下，液态模型 val PPL 显著低于固定切块（配对 3-seed，≥2σ），
  且降幅 ≥ 同配置 transformer 的降幅（形态优势是液态特有的，不是通用现象）；
- **H-E7B**（后置）：输入依赖 dt 相比均匀 dt 在流式序列上显著改善，且改善在
  长视野（E5 的 h=128）上大于短视野（dt 调制的是慢 τ 通道）。

## 3. 实验设计（探针 A）

### 数据（合成，零数据文件，机制隔离）

- 句 = 主题条件发射（每句一个 topic，句内 token 从 topic 的 Dirichlet 分布采样），
  **事件边界 = topic 切换**——让"边界"携带真实语义结构，而非随机切
- 两种切块（同 token 总数、同模型、同预算）：
  - `fixed`：顺序 view(-1, seq_len) 任意切（标准 LLM 形态）
  - `boundary`：按句边界打包成块（句不可跨块），溢出句截断，不足 pad（pad 位 labels=-100 忽略）

### 指标

1. **val PPL**（3-seed 配对，主判据）
2. （全量追加）跨窗口记忆 recall：块间 topic 绑定是否被"边界切块"保留得更好

## 4. 预注册判据（跑之前写死）

- **H-E7A 成立** ⇔ boundary 模式 3-seed 平均 val PPL < fixed − 2σ（σ 为 fixed 3-seed std）；
- **形态优势液态特有** ⇔ 液态模型的 (fixed−boundary) 降幅 ≥ 同配置 transformer 降幅的 1.5×；
- 任一不成立 → 如实记 DEAD（"事件边界形态无受力面"），**不事后移动判据**；
- 探针 B 的 patch 仅在 A 存活或 A 判负但证据指向"缺时间维度"时启动（判负记录里注明）。

## 5. 产出

- `experiments/e7_data_form_probe.py`：可跑脚本（`--mode fixed/boundary`、`--smoke`）
- 结果 JSON：3-seed 配对 PPL 矩阵（2 形态 × 3 seeds）+ 判读
- 判定：事件边界形态是否有受力面；是否启动探针 B（Δt 通道）

## 6. 依赖与边界

```bash
# 合成冒烟（CPU，零数据文件）
python experiments/e7_data_form_probe.py --mode boundary --smoke --steps 3 --seeds 0
# 全量（仍 CPU 可跑，合成长序列 + 3 seeds）
python experiments/e7_data_form_probe.py --mode boundary --steps 4000 --seeds 0 1 2
```

- **诚实边界**：合成句结构是"边界语义"的最小代理，真实语料（句/段/会话边界）是
  后续接入项；**合成结果只证明机制方向，不宣称文本质量**。
- "脑式数据"是假设不是宣称——本实验只回答"形态有没有受力面"，不回答"像不像大脑"。
- 与 E5 的关系：E5 测"视野跨度"（预测头），E7 测"切块与时间形态"（输入侧）——
  两者共同构成 L1/L4 数据形态的完整验证面。
