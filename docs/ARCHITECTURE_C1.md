# C1 架构 spec：五层液态认知栈

> 版本：0.1（2026-08-07）
> 定位：第二代类脑认知架构。不是 transformer 的替代层，而是完整认知栈。

---

## 0. 设计第一性原理

1. **稀疏是常态，不是优化**：大脑 ~860 亿神经元，每刻只有 1-2% 放电。C1 的每一层都内建稀疏——感知层稀疏采样、记忆层选择性写入、路由层 top-k 时间尺度、推理层系统1/2分流。
2. **记忆是结构，不是缓存**：工作记忆 O(1) 恒定、情景记忆快权重可跨窗口、语义记忆慢权重渐进——三层记忆各司其职，对应大脑的工作/情景/语义记忆系统。
3. **学习是预测误差，不是标签拟合**：多尺度预测编码作为自监督目标；RL 作为高层目标函数驱动推理涌现——与大脑的多巴胺奖赏学习同构。
4. **成本约束下最大化智能**（DeepSeek 哲学）：每一层都回答"同样的智能能否用更少的算力表达"。

---

## 1. L1 — 感知流原生处理（对应皮层 L4 输入层）

**问题**：Transformer 把一切 token 化——视觉变 patch、音频变帧、文本变词。但大脑接收的是**连续时间流**（光、声、本体感觉），不是离散符号。

**C1 方案**：
- `SensoryFrontend`（已有，MT-LNN 验证）：原始传感器流 → 对齐到液态时间网格（resample_uniform），带覆盖掩码标记 dropout 步
- 输出：`SensoryEncoding = (inputs_embeds, coverage_mask)`——模型知道"哪一步不可信"
- **多模态统一**：视觉/音频/文本都投影到同一液态时间空间，而非统一 token 空间（Kimi 是统一 token，C1 是统一时间）

**验证基准**：NASA 电池（非均匀采样鲁棒性，+7.7% vs LSTM +31.1%——已证明液态 ODE 原生擅长）。

## 2. L2 — O(1) 液态工作记忆（对应皮层 L2/3 工作区）

**问题**：Transformer 的 KV 缓存 O(T) 增长——上下文越长越贵。MLA 是"压缩缓存"（缓解），不是"消除缓存"（解决）。

**C1 方案**：
- 携带状态 `h_prev`：恒定大小（0.381 MB @ 1M 上下文，已验证 8063× 优势）
- 快权重矩阵（fast-weight）：跨窗口/跨会话 key→value 绑定（0.56 vs 注意力 0.000）
- **记忆控制器**（对标 DeepSeek V3 的"学习型记忆控制器"设想的液态版）：学习"什么该记住、什么该忘"——即选择性衰减（selective_decay）

**验证基准**：跨窗口记忆、O(1) 内存压测（已有）。

## 3. L3 — 稀疏时间尺度路由（对应皮层 L5 联合层）

**问题**：MoE 证明"参数稀疏有效"——每 token 只激活 37B/671B。但参数稀疏仍要算完整个前向；**计算稀疏**才能真省。

**C1 方案**：
- 13 原丝 × N 时间尺度（τ 谱），top-k 门控激活最相关的尺度
- 内生计算跳过（Endogenous Compute Skipping）：休眠通道直接跳过
- **扩容方向**（对标 MoE 扩容实验）：5 → 8/16 个时间尺度，验证"时间维度的稀疏扩容"是否像参数稀疏一样有效——**这是 C1 的第一个 scaling 实验候选**

**验证基准**：稀疏共振（6161→6645 tok/s，+7.9%，偏差 0.3%）。

## 4. L4 — 多尺度预测编码（对应皮层 L2/3 预测层）

**问题**：Next-token 预测只学"下一个词"；MTP（多 token 预测）学 3 个——但都是词层面。

**C1 方案**：
- 高维通道自上而下预测低维感知通道（预测编码，已有）
- **升级：k 步前瞻预测**（MTP 思路融入液态框架）——每步预测未来 k 步的隐状态，让每步学到 3 倍因果结构
- 预测误差 → 内部"惊讶信号"（surprise）→ 驱动 L3 路由调整 + L5 的唤醒机制

**验证基准**：WikiText-103 PPL（收敛实验进行中）、parity 任务涌现速度。

## 5. L5 — RL 推理涌现 + 系统1/2 双轨（对应皮层 L5/6 输出+调节）

**问题**：DeepSeek R1 证明纯 RL（GRPO）能逼出推理能力——不给答案只给奖励，模型自己长出思维链。**这是 C1 的最大空白，也是最快可复用的启发。**

**C1 方案**：
- **液态 GRPO**：组相对策略优化在液态状态上做——同一问题采样 n 个液态轨迹，按正确性分组相对打分，更新策略
- **系统1/2 双轨**（已有 DualSpeedSentry）：平时液态快推理（便宜），关键步激活深度递归（贵）——DeepSeek 蒸馏 R1 的"平时便宜、关键深思"哲学，我们是原生双轨而非蒸馏
- **原生探索**：液态 ODE 的连续状态空间天然适合连续动作空间的 RL——比离散 token 的 RL 更自然

**验证基准**：parity 长度外推（L≥48 selective >> stock）、合成推理任务。

## 6. 三层记忆系统（横切 L2/L3/L4）

| 记忆 | 载体 | 持久性 | 对标 |
|---|---|---|---|
| 工作记忆 | h_prev 液态状态 | 会话内 O(1) | 大脑工作记忆 / MLA 缓存 |
| 情景记忆 | fast-weight 快权重 | 跨窗口/跨会话 | 海马体情景记忆 / RAG |
| 语义记忆 | 慢权重（EWC 巩固） | 长期 | 皮层语义记忆 / 参数知识 |

## 8. 与 MT-LNN 的关系

- MT-LNN = 液态**网络**（层替换）：证明了液态动力学可行
- C1 = 液态**认知栈**（架构重构）：五层组织 + RL + 系统1/2 + 三层记忆
- 代码基础：C1 的 L1/L2/L3/L4 复用 MT-LNN 已验证组件；L5 全新
- 关系：**C1 是 MT-LNN 的认知升级，不是分支**
