# S8 结果 — E5 模型放大（d_model 1040 / 16L）

> 环境：A100-PCIE-40GB，单卡。原始数据：`/root/C1/results_s8/*.jsonl`。
> 目的:测试 S4-S7b 的"统一主干优势"是否随模型规模保持/增长。

## 结果（1040 / 16L，4000 步，2 seeds）

| horizon | unified (mean, n=2) | dedicated (mean, n=2) | 胜者 |
|---|---|---|---|
| h=8 | 1408.9（s0 1648.7 / s1 1169.1） | **1178.3**（s0 1190.9 / s1 1165.8） | dedicated |
| h=32 | 1473.1（1686.3 / 1259.8） | **1324.8**（1321.1 / 1328.5） | dedicated |
| h=128 | 1514.6（1692.3 / 1336.9） | **1426.0**（1424.3 / 1427.8） | dedicated |

## 关键发现

1. **统一头优势不随规模保持,反而反转**:在 832/12L(S4-S7b)统一全面领先;放大到 1040/16L 后 **dedicated 在三个视野全部胜出**。
2. **统一头在大模型上不稳定**:seed0(1648~1692)远差于 seed1(1169~1337),方差巨大;dedicated 两个 seed 高度一致(±3)。
3. **同预算下大模型反而更差**:832/12L 的 unified 约 1130~1314,1040/16L 的 unified 约 1169~1692 —— 4000 步对大模型是**欠训练**,且统一头的多头损失在大模型上更难平衡。

## 结论

- E5 的"统一主干优势"**是规模依赖的,不构成普适架构结论**;在更大模型上需要更长的训练预算或更好的多头损失平衡才可能复现。
- 诚实修正 S4-S7b 的表述:该优势成立于 125M(832/12L)+ 该预算区间,**不外推到更大规模**。
