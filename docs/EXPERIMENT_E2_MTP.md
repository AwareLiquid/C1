# E2 — MTP 前瞻预测：多 token 液态预测

> 状态：🟡 设计中
> 对标：DeepSeek V3 的 MTP（Multi-Token Prediction）——每步预测多个未来 token，训练效率提升
> 核心问题：**预测编码升级为 k 步前瞻，能否让液态模型每步学到 3 倍因果结构？**

---

## 1. 动机

DeepSeek V3 证明：让模型同时预测未来的 K 个 token（共享主干 + 分支头），训练信号密度提升，收敛加速且生成质量不降。

C1 的 L4（预测编码）目前只做**单步预测**——高层通道预测底层通道的下一个状态。这浪费了液态模型天然的多尺度时间结构：**13 原丝 × 5 时间尺度本来就编码了不同范围的未来**（快 τ 预测近未来，慢 τ 预测远未来）。

**E2 假设**：让预测编码的"预测目标"扩展到 k 步未来（液态状态层面 + token 层面），每步学到 3 倍因果结构，PPL 下降加速。

## 2. 与 MT-LNN 现有预测编码的差异

| | 现有（MT-LNN）| E2（C1）|
|---|---|---|
| 预测目标 | 下一 token | 未来 k=3 token |
| 预测层面 | token 层面 | **token 层面 + 液态状态层面** |
| 结构 | 单头预测 | 共享主干 + k 个前瞻头（或时序展开）|
| 损失 | CE(t+1) | Σ λ_k · CE(t+k) |

**液态版的关键创新**：在液态状态层面做前瞻——不仅预测"下一个 token"，还预测"未来 k 步的液态状态轨迹"。因为液态状态是连续时间演化的，预测未来状态是更自然的监督信号（比 token 离散目标更丰富）。

## 3. 实现方案

### 方案 A：token 层面 MTP（简单，先做）
```
输入序列 x_1..x_T
共享主干（液态模型）→ 每个位置输出 h_t
MTP 头：h_t → 预测 x_{t+1}, x_{t+2}, x_{t+3}（k 个线性头，共享主干）
损失：L = CE(x_{t+1}|h_t) + 0.5·CE(x_{t+2}|h_t) + 0.25·CE(x_{t+3}|h_t)
```
（权重递减：近未来更确定，远未来更难——参考 DeepSeek 的加权）

### 方案 B：液态状态前瞻（C1 特有，目标实验）
```
液态模型前向：h_1..h_T（每步状态）
状态前瞻头：h_t → 预测 h_{t+1}, h_{t+2}, h_{t+3}（状态回归，MSE）
+ token 前瞻：h_t → x_{t+1..t+3}（CE）
损失：L = CE 项 + λ_state · MSE 状态前瞻项
```
**意义**：状态前瞻让模型学习"未来状态如何演化"——这正是世界模型的雏形（预测下一步世界状态），比纯 token 预测更接近大脑的预测编码（Friston 自由能）。

## 4. 实验设计

| 配置 | 对照 |
|---|---|
| 基线：单步预测（现协议）| 2000 步 PPL |
| A：token MTP（k=3，加权 1/0.5/0.25）| 同预算 PPL |
| B：状态前瞻 + token MTP | 同预算 PPL |

**任务**：WikiText-103（125M 级，已有数据）+ parity（合成，快速验证）

**判据**：
- PPL 加速：同 2000 步，A/B 的 PPL 显著低于基线（>5%）
- 泛化：A/B 在长度外推上是否更好（状态前瞻应提升因果结构学习）

## 5. 产出

- `experiments/e2_mtp.py`：可跑脚本（--mode baseline|mtp|state-mtp）
- 结果：三配置的 PPL 曲线 + 长度外推对比
- 判定：状态前瞻是否为 C1 的预测编码升级方向
