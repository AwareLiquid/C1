# E6 — 跨域零样本迁移：液态栈的"冷启"能力边界

> 状态：🟡 设计完成（代码就绪，待 GPU 全量；合成冒烟已过）
> 对标：**EnergyTS「零样本冷启」**（泛领域时序基模——新场景接入不重训，快速冷启）
> 核心问题：**在多个时序域上预训练的液态模型，能否零样本迁移到从未见过的新域？**

---

## 1. 动机

EnergyTS 的产品杠杆是"千亿泛领域数据预训练 → 新站点零样本/少样本冷启"。我们此前从未测过
液态栈有没有这个能力——**这是一个能力边界问题，正是 C1 的使命**（"纯液态栈能走多远"）。
如果成立：多域预训练 + 冷启是我们产品化的关键路径（新客户接入不重训）；
如果不成立：如实记录边界，避免在 2B 路线图里押错"基模→冷启"的故事。

## 2. 假设

**H-E6**：多域联合预训练后，模型在留出域的**零样本 CE 显著低于同架构随机初始化模型**
（存在跨域迁移增益）；且"两域预训练"的增益 ≥ "单域预训练"的增益（增益来自共性而非过拟合）。

## 3. 实验设计

### 三个合成域（先验隔离：不依赖任何真实数据文件）

| 域 | 生成机制 | 结构特征 |
|---|---|---|
| A 周期 | sin(2πft) + 噪声 | 窄带谱 |
| B 自回归 | AR(1): x_t = 0.9·x_{t−1} + ε | 指数衰减 ACF |
| C 事件 | 稀疏脉冲（p≈2%）| 重尾、长尾间隔 |

三个域**生成机制互不相同**（谱结构、记忆结构、稀疏结构各占一种），保证"迁移"不是同族插值。

### 协议：留一域（leave-one-domain-out）

对每个留出域 d ∈ {A, B, C}：
1. 在其余两域上预训练（联合）→ **零样本**评估 d（不更新梯度）
2. 对照 1：同架构随机初始化模型在 d 上的 CE
3. 对照 2：仅单域预训练（随机选一个训练域）的零样本 CE

### 指标

1. 逐域零样本 CE 与迁移增益（3 留出 × 3 seeds）
2. 增益来源分解：多域预训练 vs 单域预训练（验证 H-E6 后半句）

## 4. 预注册判据（跑之前写死）

- **零样本迁移成立** ⇔ 3 个留出域的 pretrained CE 全部 < random CE（seed 平均），
  且至少 2 个域的增益 ≥ 0.2 nat；
- **泛化来源成立** ⇔ 两域预训练增益 ≥ 单域预训练增益（至少 2/3 域）；
- 若只有与训练域同族的域有增益、异族域无 → 如实记"仅近邻迁移"，**不写成泛化**；
- 不事后移动判据；全量跑前冻结。

## 5. 产出

- `experiments/e6_zero_shot_transfer.py`（`--smoke` 零数据文件，CI 可跑）
- 结果 JSON：逐域增益矩阵（留出域 × seeds × 预训练配置）

## 6. 依赖与边界

- **诚实边界**：合成域只验证**管道与协议**；真实域结论（电池/空气/事件流）需要接入 M1 数据
  管线（E2 的 prepare_data_e2.py 已是现成入口），这是后续任务。
- 这是"零样本冷启"的能力探针，**不是产品级基模训练**——产出不得被表述为"泛领域时序基模"。
- 与 E5 的关系：E5 测"视野跨度"（时间轴），E6 测"域跨度"（分布轴）；两者共同构成
  EnergyTS 对标实验组（长短时统一架构 / 零样本冷启）。
