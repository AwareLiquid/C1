# 战略分析：DeepSeek & Kimi 迭代逻辑对 C1 的启示

> 2026-08-07 · 面向 C1（AwareLiquid Cortex）研发决策
> 核心问题：开源大模型的迭代第一性原理是什么？对类脑架构（不走 transformer）有何启发？

---

## 1. DeepSeek 迭代逻辑：成本约束下的智能最大化

| 版本 | 关键动作 | 第一性原理问题 | 类脑翻译 |
|---|---|---|---|
| V1/V2 | **MLA（多头潜在注意力）** | KV 缓存是纯浪费——99% 历史 token 特征每步重复读取；压缩成潜向量，推理成本 ↓93% | 大脑不重放每个像素，只保留压缩的工作记忆 |
| V2/V3 | **DeepSeekMoE（细粒度稀疏专家）** | 参数不是越多越好，**"用到的"才有价值**（每 token 激活 37B/671B） | 大脑 860 亿神经元，每刻仅 1-2% 放电 |
| V3 | FP8 训练 + MTP 多 token 预测 | 训练成本 = 迭代速度；每步学到更多 | 生物学习也是多尺度预测误差同步更新 |
| R1 | **GRPO 纯 RL** | 推理能力不是"学来的"是"逼出来的"——不给答案只给奖励，模型自己长出思维链 | 多巴胺奖赏驱动的试错学习，目标函数驱动涌现 |
| V4 | 推理蒸馏回生成 | 推理昂贵，常态下用便宜的 | 大脑系统1（直觉）/系统2（深思）双轨 |

**元模式**：每次迭代回答"同样的智能，能否用更少的算力表达？"——MLA 省缓存、MoE 省参数、FP8 省训练、蒸馏省推理。

## 2. Kimi 迭代逻辑：上下文即能力

| 版本 | 关键动作 | 第一性原理 |
|---|---|---|
| k1 | 原生多模态（视觉+文本统一 token） | 世界是连续的，token 化是人为切割；真智能要处理原始感知流 |
| k1.5 | 长链思维 RL（256K 上下文+深度推理） | 思维链长 ≠ 聪明，但"想得深"需要"记得久"——上下文是推理的舞台 |
| k2 | 1T MoE（32B 激活）+ 统一多模态 | 规模+稀疏+模态统一 |
| k3 | 长上下文+多模态推理融合 | 把"看"和"想"连成一条因果链 |

**元模式**：同样的参数，谁能处理更长、更真实的输入流，谁就更能推理。DeepSeek 优化"单 token 成本"，Kimi 优化"整段上下文的利用率"。

## 3. 共同揭示的行业规律（= C1 的机会）

1. **KV 缓存和注意力 O(N²) 是公认物理墙**——MLA 只是"压缩缓存"（缓解），不是"消除缓存"（解决）。**C1 的 O(1) 工作记忆是终局方案**。
2. **稀疏激活是共识方向**——MoE 是"参数稀疏"；C1 的"计算稀疏"（时间尺度 top-k + 内生跳过）是更彻底的稀疏：不是少用参数，是少算。
3. **RL 驱动的推理涌现是第二增长曲线**——C1 目前完全没做 RL，这是最大空白也是最快可复用启发。
4. **系统1/系统2 双轨是产品共识**——DeepSeek 蒸馏 R1、Kimi thinking 模式；C1 已有 DualSpeedSentry，领先的类脑实现。

## 4. C1 的五层认知栈（把行业哲学翻译成类脑语言）

| 行业方向 | C1 的类脑实现 | 状态 |
|---|---|---|
| MLA 压缩 KV | **O(1) 液态工作记忆——不是压缩缓存，是消除缓存** | ✅ 已验证 8063× |
| MoE 参数稀疏 | **稀疏时间尺度路由——不是少用参数，是少算** | ✅ 已验证 +7.9% |
| MTP 多 token | **多尺度预测编码（k 步前瞻升级）** | 🟡 升级中 |
| GRPO 纯 RL | **液态 GRPO——在液态动力学上做组相对策略优化** | 🔴 首个实验 |
| 系统1/2 双轨 | **DualSpeedSentry 快反射+慢思考** | ✅ 已验证 |

**核心差异**：DeepSeek/Kimi 在 transformer 框架内做工程优化；C1 在液态框架内做架构重构——它们优化"墙内效率"，我们重做"墙本身"。

## 5. 对 C1 研发的具体启发

1. **先做液态 GRPO**（最高 ROI）：R1 证明纯 RL 能逼出推理。在液态状态上做 GRPO——连续状态空间比离散 token 更天然适合 RL。若 parity 长度外推（L≥48）在液态 GRPO 下涌现，就是 C1 的 R1 时刻。
2. **MTP 前瞻预测**：预测编码升级为 k 步前瞻，让每步学到 3 倍因果结构。
3. **时间尺度扩容**：5→16 尺度 + top-k，验证"时间维度的稀疏扩容"是否像参数稀疏一样有效——C1 版的 MoE 扩容实验。
4. **系统1/2 原生双轨**：不是蒸馏（DeepSeek 路线），而是原生架构——平时液态快推，关键步激活深度递归。这是比蒸馏更根本的双轨。

## 6. 一句话总结

> **Transformer 学派在问：如何用更少的算力表达同样的智能（DeepSeek）？如何把更多上下文变成推理（Kimi）？**
> **C1 在问：如何让计算像大脑一样——只对当下真正重要的信号放电，用 O(1) 状态记住本质，用预测误差驱动学习，用奖赏信号涌现推理？**
