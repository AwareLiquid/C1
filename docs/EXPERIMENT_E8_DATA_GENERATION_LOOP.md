# E8 — 数据生成闭环：流式形态 + 误差门控采样 + 睡眠重放

> 状态：🟡 设计完成（脚本待 E7 结案后编写；零件全部现成）
> 对标：**"数据是闭环的一环"第一性原理**（ARCHITECTURE_C1 §0 原则 5，2026-09-12）
> 核心问题：**把已有的三块零件（流式形态、surprise 加权、genreplay 重放）组装成闭环，
> 是否优于散件各自为战？**

---

## 1. 动机

大脑没有语料库，只有"感知→预测→误差→行动→新感知"的循环：数据由**模型参与生成
和组织**（误差决定练什么、睡眠重放重组、行动生成新数据）。我们的三块零件已经分散
存在且各自有实测：

| 闭环环节 | 现有资产 | 实测状态 |
|---|---|---|
| 流式形态 | E7 探针 A/B（若存活） | 待 E7 |
| 误差门控采样 | L4 surprise 信号（预测误差 → 惊讶 → 路由调节，已有） | 机制在，未接到数据采样 |
| 睡眠重放 | M2 genreplay 生成式重放（PC 稳定性 ~4× GRU） | ✅ 已实证 |

E8 = 组装实验：不是新发明，是把三个已验证/待验证的散件**接成一条数据管线**，然后
用预注册判据回答"闭环是否 > 散件之和"。

## 2. 假设

**H-E8**：在相同算力预算下，[流式形态 + surprise 加权采样 + genreplay 重放] 的
组合相比 [固定块 + 均匀采样 + 无重放] 在 val PPL 与跨窗口记忆 recall 上显著更优
（3-seed 配对 ≥2σ）；且组合优于任一单件（消融三臂）。

## 3. 实验设计

### 配置矩阵（4 臂 × 3 seeds，GPU 全量）

| 臂 | 形态 | 采样 | 重放 | 意义 |
|---|---|---|---|---|
| C0 对照 | 固定块 | 均匀 | 无 | 标准 LLM 基线 |
| C1 | 流式（E7 存活形态） | 均匀 | 无 | 形态单件 |
| C2 | 固定块 | surprise 加权 | 无 | 采样单件 |
| C3 闭环 | 流式 | surprise 加权 | genreplay 重放 | 组装全量 |

### 组件实现要点

- **surprise 加权采样**：训练时按当前模型的预测误差对样本加权（高意外多练），
  以 batch 采样权重实现（不做在线样本增删，避免分布漂移不可比）
- **genreplay 重放**：复用 M2 `experiments/liquid_pc` 的生成式重放实现；
  **必须带真实回放对照臂**（M2 已实测 PC-gen 略逊真实回放 +0.016——这个差距
  就是闭环的诚实边界，不掩盖）

## 4. 预注册判据（跑之前写死）

- **闭环成立** ⇔ C3 的 val PPL / 跨窗口 recall 显著优于 C0 且优于 C1、C2 各自
  （配对 ≥2σ，3 seeds）；
- **单件贡献可分离** ⇔ 消融三臂（C1/C2/C3）两两对比给出每件边际贡献；
- 若 C3 不显著优于 C0 → 如实记 DEAD（"闭环组装无增量"），不事后移动判据；
- 若 C3 优于 C0 但劣于某单件 → 记"组装负交互"，回炉找冲突件（不是成功）。

## 6. 依赖与边界

- **前置**：E7 结案（流式形态规格冻结）+ M2 genreplay 代码复用（已存在，无需新开发）
- **诚实边界**：① 生成式重放可能放大模型自身的系统性偏见——真实回放对照臂是
  纪律性护栏；② "闭环"不等于"具身"——本实验的闭环是数据组织闭环，不是
  agent-环境交互闭环（后者只进 roadmap，不进当前主线）；③ 不宣称"脑式数据"。
- 与 E1 的关系：GRPO 自博弈是闭环的第四个零件（行动生成新数据），E1 单独结案后
  再评估是否并入 E8 后续批次。
