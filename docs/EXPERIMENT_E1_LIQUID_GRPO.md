# E1 — 液态 GRPO：在液态动力学上涌现推理

> 状态：🔴 设计完成，待 GPU
> 对标：DeepSeek R1 的 GRPO（组相对策略优化）纯 RL 涌现推理
> 核心问题：**不给答案、只给奖励信号，液态动力学能否自己"长"出长度外推的推理能力？**

---

## 1. 动机（为什么做）

DeepSeek R1 证明了：在正确答案 + 奖励信号下，纯 RL（GRPO）能让模型涌现出长链推理——**推理不是教出来的，是逼出来的**。

MT-LNN 已有小规模证据：parity 长度外推（L 1-32 训练 → 48-128 测试）上 **selective arm >> stock arm at L≥48**（ABLATIONS.md）。但那是**监督训练**的结果——模型被教会了计数/翻转机制。

**E1 的假设**：在液态状态上做 GRPO，让模型在"正确性奖励"下**自己发现**跨长度泛化的机制——这比监督学习更接近大脑的试错学习，且可能泛化更远（R1 证明 RL 涌现的推理比 SFT 的更鲁棒）。

## 2. 任务选择：parity 长度外推（合成，奖励信号明确）

- 任务：二进制序列 → 奇偶校验（输出翻转后的序列或校验位）
- 训练：L ∈ {1..32}，测试：L ∈ {48, 64, 96, 128}
- **为什么选它**：
  - 奖励信号完全明确（整序列匹配 = 1/0）——GRPO 需要这种离散正确性
  - 已有监督基线（selective 3/3 vs stock 0/3 at L≥48）——RL 提升可以直接对照
  - 计算便宜（小模型秒级迭代）——快速验证假设

## 3. 液态 GRPO 算法（C1 版）

```
输入：问题 q（parity 序列），策略 π_θ（液态模型）
循环：
  1. 采样：对每个 q，从 π_θ 采样 G 个输出（温度采样，液态状态各异）
  2. 打分：r_i = 1[output_i == 正确]（整序列匹配）
  3. 组内归一化：A_i = (r_i - mean(r)) / std(r)   ← GRPO 用组内相对优势，不用 critic
  4. 更新：θ += η · ∇θ log π_θ(o_i|q) · A_i
     （对所有 i，按 A_i 加权；A_i>0 的输出被增强，A_i<0 被抑制）
  5. 可选：KL 约束 ||π_θ - π_ref|| 防策略崩塌
```

**与 R1 GRPO 的差异（液态版）**：
- R1 在 token 级做 RL；C1 在**液态状态演化**上做——策略的"思考"是液态 ODE 的连续状态轨迹，不是离散思维链
- 组采样利用液态的天然随机性（温度 + 初始状态扰动）——每组 G 个轨迹天然多样
- 奖励在**整序列层面**（液态模型一次前向输出整序列）——无需逐步 credit assignment

## 4. 实现要点

- 模型：复用 MTLNNModel（d_model 256 级即可，parity 任务不需要大模型）
- 参考策略 π_ref：监督训练好的 checkpoint（或随机初始化 + KL 约束）
- 采样：`model.generate` 温度采样 G=8
- 批处理：单 GPU 可并行采样 G×batch 个轨迹
- 迭代：每轮 100-500 问题 × G 样本，数十轮

**关键实验对照**：

| 臂 | 训练 | 期望 |
|---|---|---|
| A | 监督训练（现有 parity_lengthgen 协议）| selective 3/3 at L≥48（基线）|
| B | **液态 GRPO（从随机初始化）** | 是否也涌现长度外推？|
| C | 液态 GRPO（从 A 的 checkpoint 继续）| RL 微调能否进一步提升 L≥48？|

**成败判据**：
- 成功：B 或 C 在 L=48 达到 >0.7 整序列准确率（对照组监督 ~0.9）
- 有意义：B/C 的 L≥48 泛化**好于监督训练同参数量**——证明 RL 涌现的机制更根本
- 失败：B/C 卡在 L≤32（没泛化）——说明液态 RL 需要先学机制（从 A 开始）

## 5. 与系统1/2 的衔接

GRPO 成功后，下一步是**系统2 深度递归**：液态模型在"难问题"上激活更多时间尺度迭代（不是更多 token），把 RL 学到的推理变成"关键时刻想深一点"——直接对标 R1 蒸馏回 V4 的"平时便宜、关键深思"。

## 6. 产出

- `experiments/e1_liquid_grpo.py`：可跑脚本（parity 任务 + GRPO 训练 + 长度外推评估）
- 结果：三个臂（A/B/C）的 L∈{32,48,64,96,128} 准确率表
- 判定：液态 RL 是否涌现长度外推 → C1 的 R1 时刻
