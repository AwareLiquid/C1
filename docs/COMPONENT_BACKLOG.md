## T3 · 情景记忆模块（海马体式 one-shot 记忆）· 立项就绪

| 字段 | 内容 |
|---|---|
| 功能目标 | 对**单次经历**做快速编码与精确检索（一次写入即可召回） |
| 系统目标 | 支撑 one-shot 记忆与情景回放（供 T4 固化与 T9 模拟消费） |
| 输入 | 事件流（episode 结构：带时间戳的 (t, obs) 序列——DATA_FORMS §2 格式） |
| 输出 | 检索到的情景 + 回放信号 |
| 交叉点（环 3） | 海马–皮层固化对话：向 T4 提供回放；接受 T2 工作记忆写入；受 T8 显著性调制编码强度 |
| 归纳偏置 | 快速一次性编码、模式分离/完成 |
| 验证方式 | one-shot 检索基准：PMB t1 难格（64,16）recall；**判负标准（预注册）**：fastweight 臂
3-seed 配对不优于 rag(hash) 0.839 − 0.10 → DEAD（= M1 backlog B-4，已预注册，等 GPU adapter） |

**执行路径**：B-4 fastweight 臂（A100 GPU adapter 训练 + PMB t1/t2/t3 全网格对打 rag）——
skill 的 T3 与 M1 的 B-4 是同一件事，直接跑已预注册的实验即可。

## T6 · 动作选择模块（基底节 + 多巴胺 RPE）· 立项就绪

| 字段 | 内容 |
|---|---|
| 功能目标 | 用**奖赏预测误差（RPE）**驱动选择（actor–critic） |
| 系统目标 | 强化学习信号驱动行为/生成策略——L5 的机制底座 |
| 输入 | 状态价值估计 + 奖赏信号（经验轨迹 (s, a, r, s')） |
| 输出 | 动作/选择 + RPE 信号 |
| 交叉点（环 2，CBGTC） | 皮层→纹状体→苍白球→丘脑→回皮层；RPE 调制可塑性；与 T10 审慎路由共享门控 |
| 归纳偏置 | 奖赏预测误差、actor–critic |
| 验证方式 | 稀疏奖励任务被 RPE 有效驱动 vs 纯监督基线；**注意**：C1 E1 的 GRPO 已判负
（≈随机），但 GRPO ≠ RPE——E1 测的是"推理涌现"，本组件测的是"RPE 驱动选择"，
**不把 E1 的判负外推到此组件**（skill 环 2 的 CBGTC 机制未真正测过） |

**执行路径**：最小实验 = parity/合成稀疏奖励任务上的 RPE-modulated actor-critic
（液态状态 + RPE 门控），判负标准预注册后 GPU 可跑。

## T8 · 显著性模块（杏仁核 + 腹侧纹状体）· 立项就绪

| 字段 | 内容 |
|---|---|
| 功能目标 | 对输入流快速打**显著性/价值标签**（无监督） |
| 系统目标 | 决定"什么值得注意/记忆/行动"——调制 T3 编码与 T5 注意 |
| 输入 | 感知/情景信号（带显著事件的流） |
| 输出 | salience/value 标签（低维、快速） |
| 交叉点（环 1/2） | 调制注意、记忆编码、动作选择的 RPE 价值端 |
| 归纳偏置 | 快速、无监督的价值估计 |
| 验证方式 | 能否正确标注关键事件；消融后注意/记忆是否退化。最小实验：在 PMB/genreplay
协议中加 salience 门控（高显著事件写入强度 ↑），判负标准 = 记忆 recall 无提升 → DEAD |

**执行路径**：C1 L4 的 surprise 信号是雏形（预测误差），本组件把 surprise 升级为
"价值"维度（对下游写入/注意的调制），与 M3 神经调质广播（见下）共享通道。
